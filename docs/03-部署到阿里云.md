## 二、公网放行（已完成，留档）

1. 阿里云控制台 → 云服务器 ECS → 实例 → 找到这台机器 → **安全组** → 配置规则
2. 入方向 → 手动添加：
   - 端口范围：`80/80`
   - 授权对象：`0.0.0.0/0`（所有人）或者你们的固定 IP `/32`（更安全，但换网络就打不开）
   - 协议：TCP，优先级 100
3. 保存后等 10 秒，浏览器打开 `http://8.148.205.121/`

> 之前那份 `部署说明.md` 里提过：安全组规则填的「访问来源」和实际出口 IP 对不上，导致 6185/5099/6081 全都不通。这次记得把来源改成**当前真实出口 IP**，或者干脆 `0.0.0.0/0`。

## 三、⚠️ 公网暴露前必做

这个站现在是**公网可访问**的，而初始账号密码是公开的（`xiaomi/xm123456`、`zhuzhu/zz123456`）。

**放行端口后第一件事：登录 → 设置 → 账号，把两个密码都改掉。**

如果不想让陌生人访问，就把安全组授权对象改成你和她的固定 IP。家里宽带 IP 会变，变了要回来改。

## 五、以后怎么更新

在本地改完代码后：

```powershell
cd E:\lianairiji
npx vite build
tar -czf .tmp\app.tar.gz dist server package.json package-lock.json
scp -i <你的密钥>.pem .tmp\app.tar.gz root@8.148.205.121:/tmp/
ssh -i <你的密钥>.pem root@8.148.205.121 `
  "tar -xzf /tmp/app.tar.gz -C /opt/lianairiji && systemctl restart lianairiji"
```

> 只传 `dist` 和 `server`，**不要动 `/opt/lianairiji/data`**，服务器上的照片和记录不会丢。
> 如果这次改了依赖，再执行 `cd /opt/lianairiji && npm install --omit=dev`。

## 六、数据怎么来回

- **本地 → 服务器**：`node tools/snapshot.mjs` 生成只读快照到 `.tmp/release-data/`，打包后上传
- **服务器 → 本地**：`scp -r root@8.148.205.121:/opt/lianairiji/data ./data-server`

本地和服务器是**两份独立数据**，各改各的。以后想合并再说。
