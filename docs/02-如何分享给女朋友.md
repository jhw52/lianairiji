# 怎么把网站分享给女朋友看

> 网站现在就跑在你自己的电脑上（端口 3001）。别人能不能打开，取决于「她怎么连到你电脑」。
> 下面从最省事到最稳，按顺序选一个就行。

---

## 先确认：网站是活的

在你自己电脑上打开 <http://localhost:3001>，能登录就说明服务正常。

如果打不开，双击项目里的 **`start.bat`**，等窗口里出现「已启动」再试。

---

## 方案 A · 同一个 WiFi（今天就能用）

**适合**：她和你在一起、连同一个路由器。

**1. 查你的局域网 IP**

```powershell
ipconfig
```

找 `无线局域网适配器 WLAN` 下面的 `IPv4 地址`，例如 `10.44.81.4`。

**2. 放行防火墙（只需一次，需要管理员）**

右键开始菜单 →「终端(管理员)」，粘贴：

```powershell
netsh advfirewall firewall add rule name="恋爱日记3001" dir=in action=allow protocol=TCP localport=3001
```

> 第一次启动时 Windows 弹出「是否允许 Node.js 访问网络」，点**允许**也一样。

**3. 她把手机连上同一个 WiFi**，浏览器输入：

```
http://10.44.81.4:3001
```

（把 IP 换成你查到的那个）

**注意**

- 你的电脑不能关机、不能睡眠（电源设置里把「睡眠」改成「从不」）
- 路由器重启后 IP 可能会变，变了要重新告诉她
- 出了这个 WiFi 就打不开了

---

## 方案 B · Radmin VPN（你电脑上已经装了）

**适合**：她不在你身边，但你想让她随时能看。

你机器上已经有 `Radmin VPN`（当前地址 `26.128.164.32`），做法：

1. 你打开 Radmin VPN →「网络」→「创建网络」，设一个名字和密码（比如 `zhuzhu-home` / 只有你们知道的密码）
2. 她在自己电脑或手机装 Radmin VPN →「加入网络」→ 填同样的名字和密码
3. 她加入后，在网络成员列表里能看到你，记下你的 IP（`26.x.x.x`）
4. 她浏览器打开 `http://26.x.x.x:3001`

**优点**：不花钱、不用备案、不暴露公网、跨城市可用。
**缺点**：两边都要开着 Radmin VPN；电脑得开机。

---

## 方案 C · Tailscale（更现代，但国内登录可能不稳）

1. 两边都装 [Tailscale](https://tailscale.com/)，登录同一个账号（或你邀请她加入你的 tailnet）
2. 你电脑上执行 `tailscale ip -4`，得到一个 `100.x.x.x`
3. 她打开 `http://100.x.x.x:3001`

**优点**：加密隧道、自动穿透 NAT、IP 固定。
**缺点**：登录页在国内偶尔打不开，需要多点几次或换网络。

---

## 方案 D · 云服务器（要花钱 / 可能要备案）

买一台国内轻量服务器（约 100 元/年），把项目拷上去：

```bash
docker compose up -d
```

然后 `http://服务器IP:3001` 就能访问（非 80/443 端口通常不需要备案）。
想要 `https://love.你的域名` 这种好看地址，就需要域名 + 备案。

---

## 让她一开机就能看（可选）

不想每次手动双击 `start.bat`：

1. 按 `Win + R`，输入 `shell:startup`，回车
2. 把 `start.bat` 的**快捷方式**拖进这个文件夹
3. 以后开机自动启动，窗口最小化即可

---

## 安全提醒（重要）

- **立刻改密码**：初始账号 `xiaomi / xm123456`、`zhuzhu / zz123456` 是公开的，登录后到「设置 → 账号」改掉
- 不要把 `http://你的IP:3001` 发到群里、朋友圈
- 经期与亲密记录都在这个站里，属于隐私；不要用公网端口直接暴露（方案 A/B/C 都是私网，相对安全）
- 备份：定期把项目里的 `data/` 文件夹复制一份到网盘或移动硬盘

---

## 一句话总结

- **今天就想给她看** → 方案 A（同一个 WiFi，改个 IP 就行）
- **想让她随时能看** → 方案 B（Radmin VPN，你已经装了）
- **想长期稳定 + 好看域名** → 方案 D（服务器 + 域名，要花钱/备案）
