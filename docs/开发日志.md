## v2.2 · 2026-10-31 　游客登录后自动换密码（测试版）

**改动前记录（需求）**

每次游客登录后自动重置密码；想再次游客登录，只能去已登录账号的分享页看新密码/新二维码。

**实现**

- 服务端：`POST /api/auth/login` 成功后，如果登录的是只读游客，立刻调用 `rotateVisitorPassword()` 生成新密码（更新哈希 + 明文配置），并广播一次 `settings` 事件
- 影响：刚才那张「游客登录」二维码、以及任何知道旧密码的人，**立即失效**
- 站长侧：「设置 → 分享入口 → 游客登录」用 `useApi` 订阅版本变化，密码被换掉时页面自动刷新出新密码和新二维码，不用手动刷新
- 当前会话不受影响（已经进来的游客仍可继续浏览，直到退出或会话过期）

**验证（3003 演示实例）**

- 初始密码 `Lv8sQ2xR` → 登录一次 → 页面显示新密码 `Awt55I6Q`
- 用旧密码再登录：**401**
- 用新密码登录：**200**

**当前状态**

- 测试版：✅ 本地已生效
- 正式版：⏳ 未推送

**事故记录（必须留痕）**

用 PowerShell 批量给 5 个页面文件加 `write-only` 时，脚本把文件里所有的 `<` 替换成了字母（`Albums/Wishes/Whisper` → `d`，`Timeline/Anniversaries` → `b`），导致 `ddiv`、`useApidany>` 这种内容，构建直接失败。

修复过程：
1. 按标签名还原 `ddiv → <div`、`d/div> → </div>`
2. 补大写组件 `dIcon → <Icon`、闭合组件 `b/Modal → </Modal`
3. 还原泛型 `useApidany> → useApi<any>`、`Mapdstring → Map<string`
4. 还原比较运算符 `a[0] d b[0] → a[0] < b[0]`、`days b= 7 → days <= 7`
5. 还原空 Fragment `d> → <>`
6. 重新构建通过，逐页人工抽查

**教训**：不用 PowerShell 的字符串替换批量改源码；要批量改，先复制一份备份，或者改用 Edit 工具逐个改。

**验证（本地 3001）**

- 空演示：0 天、0 照片、接口全空、写操作 403
- 只读：能看到 257 天和照片，写操作 403，设置入口与上传按钮隐藏
- 日历默认落在「大事记」

- 点侧边栏头像进入 `/profile`

## v1.2 · 2026-10-30 　日历与生活

**做了什么**

- 日历页：月视图（周一为每周第一天）、经期/亲密/纪念日/预测四种标记、点击某天弹出抽屉、记经期与记亲密表单
- 经期预测：最近 6 个有效周期的中位数、经期长度中位数、下次开始/结束、排卵日与易孕期、数据不足时的降级提示
- 纪念日：每年/每月/仅一次，倒计时排序（临近在前、过去的沉底），7 天内高亮
- 心愿清单：分类、勾选打卡（记完成时间）、进度条、按分类筛选
- 悄悄话：双人留言墙、左右分栏、仅自己可见、对方的悄悄话自动标记已读
- 服务端新增 `routes-life.mjs`、`predict.mjs`；三张表在 v1.1 建库时已预留，只给 `messages` 补了 `visibility` / `read_at` 两列（自动迁移）

**关键实现**

- 预测全部用 UTC 日期做整数运算，不受时区影响；样本 < 2 时用 28 天并标「数据不足」
- 经期区间禁止重叠，冲突返回 409
- 所有写操作沿用 SSE 广播 + `rev` 乐观锁

**修掉的 Bug**

| 现象 | 原因 | 修法 |
|---|---|---|
| 日历所有格子都带红框 | `data-today={false}` 渲染成字符串 `"false"`，`[data-today]` 属性选择器照样命中 | 改成 `isToday || undefined` |
| 修完后格子全隐形 | 格子底色与卡片同色 | 给 `.cal-cell` 加纸色底 + 1px 边框 |
| 心愿清单输入框被挤成 28px | 自定义 `.select { width:100% }` 在 Tailwind 之后，压过了 `sm:w-[110px]` | select 改内联宽度 + `shrink-0` |
| 已完成的愿望重复出现 | 建库种子数据与演示数据重名 | 去掉建库时预置的两条待办 |
| 纪念日把「912 天前」排在最前 | 只按天数升序 | 先按是否已过排序，再按天数 |

**接口**

POST /api/intimacy PATCH/DELETE /api/intimacy/:id
