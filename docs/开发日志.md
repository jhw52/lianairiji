## v4.2 · 2026-11-01 　收藏是最高权限：锁定时全站不可见（测试版）

**需求**

收藏隐藏时，收藏过的照片在任何地方都不该出现。

**实现**

- 服务端：所有列表接口支持 `hideFav=1`
  - `/api/home`：最近照片与「照片/视频」计数都排除收藏
  - `/api/photos`（加载更多）
  - `/api/media`（按天/全部/视频，收藏 scope 本身不受影响）
  - `/api/moments`（时间轴挂图）
  - `/api/albums`（封面与照片数）
- 客户端：`PrivacyProvider` 维护一个模块级开关，`api()` 在锁定状态下给所有 GET 自动追加 `hideFav=1`
- 收藏解锁/隐藏时，首页、相册、手动相册详情都会重新取数

**验证（3003 演示实例，测试后已还原收藏状态）**

- 把唯一一张照片设为收藏后：
  - 不隐藏：`/api/media` 1 条；隐藏：**0 条**
  - 首页锁定：`counts.photos = 0`、`recent = 0`
  - 相册页锁定：0 张，且没有「收藏」页签
  - 连点三下解锁：照片重新出现（1 张），「收藏」页签出现

**当前状态**

- 测试版：✅ 本地已生效

## v4.0 · 2026-11-01 　沙盒按会话隔离 / 亲密自动隐藏 / 收藏受控（测试版）

**需求**

1. 演示沙盒按会话隔离
2. 开启亲密记录后，切到别的功能页自动重新隐藏
3. 收藏按钮隐藏，连点三下「相册」才出现；收藏照片的标记也一起隐藏；批量操作增加收藏 / 取消收藏（取消收藏只在收藏页）

**实现**

- **沙盒隔离**：沙盒目录从 `data/sandbox` 改成 `data/sandbox/<session_id>`，每个游客会话一个独立库和媒体目录
  - 退出只删自己那份（`resetSandbox(session_id)`），不影响别人
  - `/files` 按会话从自己的媒体目录取文件，越权路径直接 400/404
  - 打开句柄做 LRU 上限 16，避免多人演示时句柄堆积
- **亲密自动隐藏**：去掉 sessionStorage，改成组件内 state，离开日历页就复位
- **收藏受控**：
  - 新增 `PrivacyProvider`（`favUnlocked`），默认关闭
  - 侧边栏连点三下「相册」（≤900ms）解锁，弹提示「收藏已显示」
  - 未解锁时：相册页不显示「收藏」页签、照片上的星标、灯箱里的收藏按钮
  - 批量操作：解锁后多出「收藏」；在收藏页多出「取消收藏」

**验证**

- 沙盒：A 会话加待办，B 看不到；A 退出后 B 的沙盒仍在；A 的图 B 取 404，A 自己 200
- 日历：解锁后切到时间轴再回来，页签恢复「经期」
- 收藏：默认页签无「收藏」；连点三下后出现并提示；批量收藏把一张改成 favorite=true，收藏页「取消收藏」改回 false

**当前状态**

- 测试版：✅ 本地已生效
- 正式版：⏳ 待推送

## v1.5 · 2026-10-30 　头像历史、系统头像与站点图标

**做了什么**

- 头像支持三种来源：上传照片 / 8 个内置系统头像 / 从「最近用过」里切换
- 新增 `avatar_history` 表：每次换头像记一条（同值不重复记），最多列出最近 30 个
- 系统头像：`client/public/avatars/` 下 8 个手绘 SVG（小猫、兔子、小熊、熊猫、狐狸、小鸡、青蛙、企鹅），本地文件，不走网络
- 头像在整站统一：侧边栏底部、悄悄话作者、设置页预览
- 站点图标（左上角）：设置页上传 → `settings.site.logo_media_id`，同时作用于导航顶部、登录页、浏览器标签 favicon
- 新增 `media.usage` 字段（gallery / avatar / logo / hero）：头像、图标、背景这类工具图不再混进「相册」和「最近的照片」

**修掉的 Bug**

| 现象 | 原因 | 修法 |
|---|---|---|
| 侧边栏头像变成破图 | 只取了 `/files/${avatar}`，没处理 `sys:` 前缀 | 统一走 `avatarSrc()` |
| 上传的头像/图标出现在相册里 | 都往 media 表写，没有用途区分 | 加 `usage`，相册只读 `gallery` |

**接口**

```
GET  /api/me/avatars           当前头像 + 历史（去重，最多 30）
POST /api/me/avatar            { mediaId } | { path: 'sys:cat' } | { historyId }
DELETE /api/me/avatar
PUT  /api/settings             { logoMediaId }
```

**验证**

- 选系统头像 → 侧边栏立即变；再换一个 → 「最近用过」出现两个，点旧的能切回
- 上传站点图标 → 导航顶部、浏览器标签同步变化
- 上传头像/图标后，首页照片数仍为 0（工具图不计入）

## v1.2 · 2026-10-30 　日历与生活

**做了什么**

- 日历页：月视图（周一为每周第一天）、经期/亲密/纪念日/预测四种标记、点击某天弹出抽屉、记经期与记亲密表单
- 经期预测：最近 6 个有效周期的中位数、经期长度中位数、下次开始/结束、排卵日与易孕期、数据不足时的降级提示
- 纪念日：每年/每月/仅一次，倒计时排序（临近在前、过去的沉底），7 天内高亮
- 心愿清单：分类、勾选打卡（记完成时间）、进度条、按分类筛选
- 悄悄话：双人留言墙、左右分栏、仅自己可见、对方的悄悄话自动标记已读
- 服务端新增 `routes-life.mjs`、`predict.mjs`；三张表在 v1.1 建库时已预留，只给 `messages` 补了 `visibility` / `read_at` 两列（自动迁移）

**关键实现**

- 预测全部用 UTC 日期做整数运算，不受时区影响；样本 < 2 时用 28 天并标「数据不足」
- 经期区间禁止重叠，冲突返回 409
- 所有写操作沿用 SSE 广播 + `rev` 乐观锁

**修掉的 Bug**

| 现象 | 原因 | 修法 |
|---|---|---|
| 日历所有格子都带红框 | `data-today={false}` 渲染成字符串 `"false"`，`[data-today]` 属性选择器照样命中 | 改成 `isToday || undefined` |
| 修完后格子全隐形 | 格子底色与卡片同色 | 给 `.cal-cell` 加纸色底 + 1px 边框 |
| 心愿清单输入框被挤成 28px | 自定义 `.select { width:100% }` 在 Tailwind 之后，压过了 `sm:w-[110px]` | select 改内联宽度 + `shrink-0` |
| 已完成的愿望重复出现 | 建库种子数据与演示数据重名 | 去掉建库时预置的两条待办 |
| 纪念日把「912 天前」排在最前 | 只按天数升序 | 先按是否已过排序，再按天数 |

**接口**

```
GET  /api/calendar?month=YYYY-MM     整月聚合（经期/亲密/纪念日/预测）
GET  /api/cycles/summary             预测与统计
POST /api/cycles  PATCH/DELETE /api/cycles/:id
POST /api/intimacy PATCH/DELETE /api/intimacy/:id
POST /api/anniversaries PATCH/DELETE /api/anniversaries/:id
POST /api/todos    PATCH/DELETE /api/todos/:id
POST /api/messages POST /api/messages/read DELETE /api/messages/:id
```

**验收结果**

- 10 项接口测试全部通过（未登录拦截、重叠 409、预测重算、过期 rev 409、心愿打卡、私密留言…）
- 桌面与手机截图见 `docs/screenshots/20~25`

**已知限制**

- 经期记录允许「只填开始」，但跨月进行中的天数不会自动写回结束日
- 悄悄话的「已读」是对方打开页面即标记，不是逐条确认
